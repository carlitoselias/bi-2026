Principles of a visual system

What is a visual system?

A visual system is a stable, consistent set of rules that governs every visual aspect of your data communication. Its purpose is to build a visual language that works predictably and effectively, beyond an attractive style. Each decision must be deliberate, documented and repeatable.

Final goal: Ensure consistency and readability in every visualization, across media and formats.

04
Principles of a visual system

Why it matters

Cognitive and communication impact

A well-built visual system is a cognitive tool that changes the reader’s experience. Visual consistency frees mental resources to understand the message instead of deciphering the format.

Reduce visual fatigue

The eyes and brain do not need to keep adjusting to new styles and conventions.

Reduce ambiguity

Clear rules remove conflicting interpretations and confusion about what each element means.

Speed up understanding

The reader recognizes familiar patterns and can process information faster.

Reinforce identity

Your communication becomes recognizable and memorable, building professional credibility.

Remove repeated learning

Multiple charts follow the same visual logic, without a repeated learning curve.

Direct benefit

The reader can focus on the story and data, without working out how to read each new chart.

05
Principles of a visual system

The visual system of The Economist

Leading media and visual communication organizations have spent years developing robust, recognizable visual systems. Studying these examples helps us identify successful patterns.

This system has key features: consistent typography, controlled and documented color palettes, annotations that follow a common pattern, and modular layouts that can adapt while retaining their identity.

Anatomy of a professional visualization

Before designing a complete system, we must understand the basic components of a professional visualization. Each element has a specific function and requires deliberate decisions.

The entire visual system builds on this basic structure. Each component needs clear style rules that remain consistent across visualizations.

Active title

  • Communicate a finding: explain what is happening.
  • Be direct and specific. Use active verbs.
  • Include the size of the change when relevant.
  • Avoid unnecessary technical jargon.
  • Keep the same tone and typographic style across the series.
  • Use readable size and contrast, without dominating the visualization.

Subtitle and context

  • State the unit of measurement: count, percentage or currency.
  • State the period and measurement frequency.
  • Define the scope: population, location or universe analyzed.
  • Identify the source and collection date when relevant.
  • Use smaller, lighter type than the title.
  • Place it directly below the title, with consistent spacing.

Axes

  • Choose axes to suit the comparison; do not leave the choice to the software.
  • Keep the same weight, color and typography throughout the series. Use thin strokes and readable labels.
  • For bars and areas, include zero to compare magnitudes without distorting their proportions.
  • For lines, you can narrow the scale to show variation. Make the selected range visible.
  • Name both axes and state their units. Rotate the Y-axis title 90° to keep it beside the scale.
  • Avoid crowded axes: use few ticks, regular intervals and easy-to-read values.
  • Use a consistent format: thousands separators, only necessary decimals and explicit units.

Gridlines

  • Use guides only when they help compare values. Omit them if they add nothing.
  • In these charts, horizontal guides help read the Y-axis scale.
  • Avoid vertical guides when they add no necessary reference.
  • Use thin, low-contrast gray lines: the data must stand out first.
  • Align guides with the main axis ticks, without adding an unnecessary grid.
  • Keep the same color, weight and opacity across all charts.

Marks and lines

  • For bars, keep width and spacing uniform.
  • If you round corners, apply the same treatment to all bars.
  • For lines, define a moderate weight. Secondary references should be thinner.
  • For points, use a uniform size unless size encodes another variable.
  • Reduce opacity when points overlap.
  • Document these values and reuse them throughout the project; avoid arbitrary style changes.

Color: the golden rule

  • Reserve one accent for what matters: here, April’s data.
  • Give each color a stable meaning and keep it across charts.
  • Use a neutral base for data, axes and guides; supporting elements must not compete for attention.
  • Avoid automatic rainbows, random colors and too many saturated hues.
  • Also highlight data with shapes or labels so they remain recognizable without color.
  • Document the palette and its uses: data, emphasis and support.

Spacing and margins

  • Keep outer margins wide and uniform. Content must not touch the edges.
  • Define a spacing scale, such as 8, 16 and 24 px, and reuse it throughout the piece.
  • Inside boxes and notes, leave space between the text and edges.
  • Keep related elements close and separate groups: title and subtitle, charts and notes.
  • Balance the empty space. Avoid crowded content and large gaps without a purpose.
  • Do not fill every available space: let readers take in data and text comfortably.

Typography

  • Choose a readable typeface for data. Here we use a sans serif throughout.
  • Set a hierarchy with weights: bold titles, medium subtitles and regular text.
  • Use a clear size scale: larger titles, medium labels, smaller annotations and sources.
  • Repeat the same style for the same function: both charts share labels, numbers and subtitles.
  • Avoid decorative typefaces, arbitrary changes and sizes that make data hard to read.

Iconography

  • Choose one style: outline or solid. Avoid arbitrary mixtures.
  • Keep the same stroke weight and end treatment across all icons.
  • Use a common scale and visually balanced sizes.
  • Keep icons neutral and reserve the accent for a relevant state, such as an active filter.
  • Use simple, recognizable shapes. Add a label when it helps explain the action.

Principles of a visual system

Composition and layout

  • Start with the key figure: give it a visible position and a size that signals its importance.
  • Give the main chart more space. Supporting charts should complement it, without competing.
  • Place annotations close to the data they explain.
  • Keep the source, period and technical notes in predictable places; put the method at the foot.
  • Align elements in columns and use consistent proportions, without random floating pieces.
  • Define a clear reading path: key figure, main chart, context and source. Reuse it in similar pieces.

Using the visual system

Different charts, one visual language.

We have built the theoretical foundations of a visual system. Now we apply these principles to specific chart types. Each type presents its own challenges, but all must follow the same basic rules of your system.

Using the visual system

Bars

The workhorse of data visualization.

Their simplicity is their strength, but execution needs discipline to maintain clarity and a professional result. The same rules apply to horizontal bars, which are useful for long labels.

19
Using the visual system

Time series

Time series tell stories of change over time.

They are especially useful for revealing trends, cycles and turning points. Careful design turns time-based data into understandable stories. Across charts, keep the date range, labels and line styles consistent to support comparison.

Using the visual system

Maps

Maps show how data are distributed across a territory.

They reveal concentrations, differences between areas and spatial patterns. A subtle geographic base keeps data in focus. To compare territories or periods, keep the same projection and scale. Color must retain its meaning for the same variable; here we show two different uses.

Using the visual system

Scatterplots

Essential for visualizing relationships between two numeric variables.

They reveal correlations, patterns and outliers. Their effectiveness depends on clear reading and an honest representation of the data. They also help explore unexpected relationships and test hypotheses.

22
Using the visual system

Heatmaps

Useful tools for visualizing data density and revealing patterns.

They help explore large amounts of information. Effective design is essential to make these visualizations informative and easy to interpret.

Using the visual system

Pie charts

Use only in an emergency and at your own risk.

They show how a total splits across a few categories, especially when one dominates. We compare angles and areas less precisely than lengths: prefer bars when differences are small. The selector lets you explore an alternative with the same data.

Visual stress tests

A robust visual system stays clear under different conditions.

View in grayscale

Check that emphasis, contrast and hierarchy remain clear when color is removed.

Simulate color blindness

Use a simulator to check colors. Reinforce differences with labels or shapes.

View on different screens

Check readability on large screens, phones and projectors. Adjust content, contrast and label sizes for each medium.

Five-second test

Press to see the chart.

What did you see first: the title, the emphasis, the main pattern or the noise? Check whether attention follows the message.
